# Busy Beaver in Bend

Proving Busy Beaver values in Bend 2, as a test of Bend's claims: that proofs
make code trustworthy without reading it, and that Bend checks them fast.

BB(n) is the longest that any n-state, two-symbol Turing machine runs from a
blank tape before halting. A machine that halts can be watched halting; one
that never halts can only be proven not to. Known values: BB(2) = 6,
BB(3) = 21, BB(4) = 107, BB(5) = 47,176,870 (all proven in Coq by Coq-BB5).

## Files

- `tm.bend`: machines, the simulator, two-state machines.
- `champions.bend`: the record holders for n = 2 to 5.
- `abs.bend`: the decider that proves machines never halt, and `check`.
- `logic.bend`, `sound.bend`: the decider's soundness and the bound lemma.
- `bb2.bend`, `bb2_elim.bend`: all two-state machines (generated by `gen_bb2.py`).
- `fast.bend`: long runs in the checker, with binary counters.
- `LAWS.bend`: what the project claims. `PROOF.bend`: the proofs.
- `main.bend`, `survey.bend`: native runs of the champions and of all two-state machines.

## Run

```sh
bend PROOF.bend --verdict              # the gate
bend main.bend -o bb && ./bb           # run the champions
bend survey.bend -o survey && ./survey # tally the two-state machines
python3 gen_bb2.py                     # regenerate bb2.bend and bb2_elim.bend
```

## Status

Proven under `--verdict` (2.6 s): BB(2) = 6, i.e. `bb2_champion` and
`bb2_bound`; also that the BB(3) and BB(4) champions halt at exactly 21 and
107 steps. Not yet: the upper bounds for BB(3) and BB(4). See
`DEVELOPMENT.md` for how the proof works, the timings against Coq, and what
BB(3) would take.
